# OpenSwitcher

> **Легковесный, бесшумный и полностью открытый переключатель раскладки клавиатуры для macOS (Apple Silicon & Intel).**

---

## ⚡ Особенности

* **Графический интерфейс на SwiftUI:** полноценное окно настроек (`Настройки...` или `⌘,` в строке меню) с вкладками:
  * **Основные:** переключатели автопереключения, двойного Shift и статус системных разрешений.
  * **Исключения:** визуальный список приложений с возможностью добавления любой программы через окно выбора (`+`).
  * **О программе:** информация о версии, потреблении ресурсов и открытом исходном коде.
* **Автоматическое переключение раскладки (RU ↔ EN):** мгновенно определяет язык ввода по буквосочетаниям и n-граммам и исправляет ошибочно набранное слово.
* **Двойной Shift (Double-Shift):** быстрое нажатие клавиши `Shift` дважды исправляет последнее набранное слово или выделенный текст на противоположную раскладку.
* **Фоновый режим в строке меню (Menu Bar):** иконка `⌥ OS` в менюбаре без лишних окон и иконки в Dock (`LSUIElement = true`).
* **Приложения-исключения:** автоматически не переключает в терминалах (`Terminal`, `iTerm2`, `Ghostty`, `Alacritty`) и IDE (`VS Code`, `Xcode`, `JetBrains`), чтобы не ломать набор команд и кода.
* **Никаких подписок и триалов:** 100% бесплатный и без ограничений по времени.
* **Полная приватность:** без телеметрии, без сетевых запросов и сторонней аналитики.
* **Минимальный размер:** релизный бандл весит всего **~290 КБ** (в сотни раз легче аналогов).

---

## 🏗 Архитектура

* **`LayoutManager.swift`** — взаимодействие с Carbon TIS (Text Input Source) для моментального переключения раскладок macOS.
* **`KeyboardMapper.swift`** — таблица взаимного отображения символов между QWERTY и русской ЙЦУКЕН (включая знаки препинания).
* **`LanguageDetector.swift`** — алгоритм эвристического распознавания ошибочной раскладки на основе невозможных буквосочетаний и частотных корней.
* **`EventTapManager.swift`** — глобальный перехват `CGEventTap` для отслеживания набора, Backspace, пробелов и двойного Shift.
* **`AppExceptions.swift`** — управление списком исключений с сохранением в `UserDefaults`.
* **`StatusBarController.swift`** — меню управления в строке состояния macOS.

## 🚀 Сборка и запуск

### 1. Сборка `.app` бандла
```bash
cd /Users/admin/.gemini/antigravity/scratch/OpenSwitcher
./bundle.sh
```

### 2. Запуск приложения
```bash
open OpenSwitcher.app
```
(или скопируйте `OpenSwitcher.app` в `/Applications`).

## 🔐 Разрешения (Accessibility)

Для перехвата нажатий клавиш macOS требует системное разрешение:
1. Откройте **Системные настройки** (`System Settings`) → **Конфиденциальность и безопасность** (`Privacy & Security`) → **Универсальный доступ** (`Accessibility`).
2. Включите переключатель напротив **OpenSwitcher** (или добавьте его через кнопку `+`).
